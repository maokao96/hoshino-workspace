Claude Code を入れる

普段お使いの Claude と同じアカウントで使えます。ターミナル（黒い画面）は使いません。普通のアプリとして入ります。

Mac をお使いの場合

Mac 版をダウンロード
ボタンで開かないとき

下のアドレスをブラウザのアドレス欄に貼り付けても、同じものが手に入ります。

https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect

  1. ダウンロードしたファイルを開き、Claude をアプリケーションフォルダへドラッグします
  2. Claude を起動して、いつものアカウントでサインインします
  3. 画面の上のほうにある Code を押します

Windows をお使いの場合

Windows 版をダウンロード
ボタンで開かないとき

下のアドレスをブラウザのアドレス欄に貼り付けても、同じものが手に入ります。

https://claude.ai/api/desktop/win32/x64/setup/latest/redirect

  1. ダウンロードしたファイルを開いて、そのままインストールします
  2. Claude を起動して、いつものアカウントでサインインします
  3. 画面の上のほうにある Code を押します
Windows だけ、もうひとつ必要です

初めて Code を押したとき、「Git for Windows が必要です」という案内が出ることがあります。出たら、案内に従って入れてください。入れたあと Claude を一度閉じて、開き直します。

Mac の場合は不要です。

こう見えたら成功です

Claude の画面の上に Code という項目があって、押すと作業を始める画面に切り替わります。

Code を押したら、料金プランの案内が出た

Claude Code は有料プラン（Pro / Max など）でのみ使えます。無料プランでは使えません。

星野さんは有料プランに入っておられると伺っているので、この案内が出た場合は、ログインしているアカウントが別のものになっている可能性があります。一度サインアウトして、いつものアカウントで入り直してみてください。

作業場を受け取る

作業場はフォルダひとつです。GitHub というサービスに置いてあるので、そこから星野さんのパソコンに持ってきます。ここが今日いちばん手数が多いところです。3つに分かれます。

① 招待のメールを承諾する

登阪さんから、GitHub の招待メールが届きます。開いて、承諾してください。GitHub のアカウントをお持ちでなければ、その画面でそのまま作れます。

こう見えたら成功です

ブラウザに、作業場のファイル一覧が表示されます。はじめに.html など、いくつかの名前が並んでいれば大丈夫です。

② GitHub Desktop を入れる

ファイルを持ってくるためのアプリです。これも普通のアプリとして入ります。

GitHub Desktop をダウンロード
Mac の方は、2種類あります

Apple silicon と Intel chip のどちらかを選びます。分からないときは、画面左上のリンゴマーク →「この Mac について」で確認できます。近年の Mac はほとんど Apple silicon です。

Windows の方は「Download for Windows (64bit)」を選んでください。

入れたら起動して、さきほど承諾したときの GitHub アカウントでサインインします。

③ 作業場を手元に持ってくる

GitHub Desktop で Clone a repository（リポジトリをクローン）を選ぶと、星野さんが招待されている作業場が一覧に出ます。それを選んで、保存する場所を決めて、Clone を押します。

保存する場所は、あとで自分で見つけられる所に

書類フォルダの中など、分かりやすい場所にしてください。ここを覚えておくと、次の手順が楽です。

こう見えたら成功です

保存した場所に、作業場のフォルダができています。開くと、さきほどブラウザで見たのと同じファイルが入っています。

招待のメールが見つからない

迷惑メールに入っていることがあります。差出人は GitHub です。

それでも見つからないときは、登阪さんにご連絡ください。送り先のメールアドレスを確認して、送り直します。

作業場を開く

Claude に「このフォルダで作業して」と教えます。

Claude の Code の画面で Select folder（フォルダを選ぶ）を押して、さきほど保存したフォルダを選びます。

「このフォルダを信頼しますか」と聞かれます

初めて開くフォルダでは、必ずこの確認が出ます。信頼する（はい）を選んでください。登阪さんが用意したフォルダです。

こう見えたら成功です

画面にフォルダの名前が表示され、Claude に話しかけられる入力欄が出ています。

選ぶフォルダがどれか分からない

ひとつ前の手順で Clone を押したときに指定した場所を開いてください。そこに作業場の名前のフォルダができています。

GitHub Desktop の画面で、メニューの Repository →「Show in Finder」（Windows は「Show in Explorer」）を押すと、その場所が開きます。

何度も「これをしていいですか」と聞かれます

Claude がファイルを読んだり書いたりするたびに、確認が出ます。うるさく感じますが、これは安全のための仕組みです。勝手に何かが起きないようになっています。

最初のうちは、出てきたら「はい」で進めて構いません。慣れてきたら、まとめて許可する設定に変えられます。

このあとは、いま何があるかを6問ほど伺います。5分ほどです。分からないものは「分からない」で大丈夫です。それが済んだら、何をどの順番で作るかをまとめた紙をお見せして、そこから実際に作りはじめます。

安心していただきたいこと

  • 壊しても、元に戻せます。この作業場は変更の履歴を全部持っています。「さっきの状態に戻して」と言えば戻ります。星野さんが操作を覚える必要はありません
  • スプレッドシートの原本には手を加えません。読むだけです。作ったものが気に入らなければ、捨ててやり直せます
  • お客さんの情報は、星野さんのパソコンに置いたまま扱います。置き場所は星野さんが決めます
  • 今日、名簿は1件も要りません。まず道具を入れて、話をするところまでです
  • 途中でやめて大丈夫です。次に開いたとき、続きから再開できます
  • 分からなくなったら、このページに戻ってきてください。作業場のフォルダの中に、いつでも入っています
