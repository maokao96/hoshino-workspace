Claude Code を入れる

普段お使いの Claude と同じアカウントで使えます。ターミナル（黒い画面）は使いません。普通のアプリとして入ります。

Mac をお使いの場合

Mac 版をダウンロード
ボタンで開かないとき

下のアドレスをブラウザのアドレス欄に貼り付けても、同じものが手に入ります。

https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect

  1. ダウンロードしたファイルを開き、Claude をアプリケーションフォルダへドラッグします
  2. Claude を起動して、いつものアカウントでサインインします
  3. 画面の上のほうにある Code を押します
初回だけ、確認が出ることがあります

「"Claude"はインターネットからダウンロードされたアプリケーションです。開いてもよろしいですか？」——「開く」で進めてください。Mac が初めて開くアプリに毎回出す確認です。

Windows をお使いの場合

Windows 版をダウンロード
ボタンで開かないとき

下のアドレスをブラウザのアドレス欄に貼り付けても、同じものが手に入ります。

https://claude.ai/api/desktop/win32/x64/setup/latest/redirect

  1. ダウンロードしたファイルを開いて、そのままインストールします
  2. Claude を起動して、いつものアカウントでサインインします
  3. 画面の上のほうにある Code を押します
初回だけ、青い画面が出ることがあります

「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を選んでください。Windows が初めて見るアプリに毎回出す確認です。

Windows だけ、もうひとつ必要です

初めて Code を押したとき、「Git for Windows が必要です」という案内が出ることがあります。出たら、案内に従って入れてください。入れたあと Claude を一度閉じて、開き直します。

Mac の場合は不要です。

こう見えたら成功です

Claude の画面の上に Code という項目があって、押すと作業を始める画面に切り替わります。

Code を押したら、料金プランの案内が出た

Claude Code は有料プラン（Pro / Max など）でのみ使えます。無料プランでは使えません。

星野さんは有料プランに入っておられると伺っているので、この案内が出た場合は、ログインしているアカウントが別のものになっている可能性があります。一度サインアウトして、いつものアカウントで入り直してみてください。

作業場を受け取る

このページを、お手元のフォルダの中から開いている方へ

この段は、もう済んでいます。フォルダが手元にあるからこのページが開けています。印を3つ付けて、ステップ3へ進んでください。

作業場はフォルダひとつです。GitHub というサービスに置いてあるので、そこから星野さんのパソコンに持ってきます。ここが今日いちばん手数が多いところです。3つに分かれます。

① 招待のメールを承諾する

登阪さんから、GitHub の招待メールが届きます。開いて、承諾してください。GitHub のアカウントをお持ちでなければ、その画面でそのまま作れます。

こう見えたら成功です

ブラウザに、作業場のファイル一覧が表示されます。はじめに.html など、いくつかの名前が並んでいれば大丈夫です。

② GitHub Desktop を入れる

ファイルを持ってくるためのアプリです。これも普通のアプリとして入ります。

GitHub Desktop をダウンロード
Mac は、2種類から選びます

Apple silicon と Intel chip のどちらかを選びます。分からないときは、画面左上のリンゴマーク →「この Mac について」で確認できます。近年の Mac はほとんど Apple silicon です。

Windows は1つだけです

「Download for Windows (64bit)」を選んでください。

入れたら起動して、さきほど承諾したときの GitHub アカウントでサインインします。ブラウザが開いて、承認するとアプリに戻ってきます。

「Signing in…」のまま戻ってこない

ブラウザで承認したのに、GitHub Desktop が「Signing in…」の表示のまま止まることがあります（Windows で報告されている不具合です）。

GitHub Desktop をいったん閉じて、開き直してください。たいていはこれでサインイン済みになっています。それでも駄目なら、登阪さんにご連絡ください。

③ 作業場を手元に持ってくる

GitHub Desktop で Clone a repository（リポジトリをクローン）を選ぶと、星野さんが招待されている作業場が一覧に出ます。それを選んで、保存する場所を決めて、Clone を押します。

保存した場所を、ここに書いておけます。書類フォルダの中など、あとで自分で見つけられる所にしてください。次の手順で使います。

こう見えたら成功です

保存した場所に、作業場のフォルダができています。開くと、さきほどブラウザで見たのと同じファイルが入っています。

招待のメールが見つからない

迷惑メールに入っていることがあります。差出人は GitHub です。

それでも見つからないときは、登阪さんにご連絡ください。送り先のメールアドレスを確認して、送り直します。

一覧に作業場が出てこない

いちばん多いのは、①の招待をまだ承諾していない場合です。メールに戻って承諾してから、GitHub Desktop の一覧を更新してください。

次に多いのは、GitHub Desktop にサインインしたアカウントが、招待を受けたアカウントと違う場合です。招待メールが届いたアドレスと、サインインしているアカウントが同じか確認してください。

それでも出てこないときは、登阪さんにご連絡ください。

作業場を開く

Claude に「このフォルダで作業して」と教えます。

Claude の Code の画面で、順にこう進みます。

  1. どこで動かすかを選びます。「Local」を選んでください。星野さんのパソコンの中だけで動かす、という意味です
  2. Select folder（フォルダを選ぶ）を押して、さきほど保存したフォルダを選びます
  3. 使う AI の種類を選ぶ画面が出たら、そのままで結構です。あとから変えられます
「このフォルダを信頼しますか」と聞かれます

初めて開くフォルダでは、この確認が出ます。信頼する（はい）を選んでください。登阪さんが用意したフォルダです。

こう見えたら成功です

画面にフォルダの名前が表示され、Claude に話しかけられる入力欄が出ています。

選ぶフォルダがどれか分からない

ひとつ前の手順で Clone を押したときに指定した場所を開いてください。そこに作業場の名前のフォルダができています。

GitHub Desktop の画面で、メニューの Repository →「Show in Finder」（Windows は「Show in Explorer」）を押すと、その場所が開きます。

話しかける

ここから先は、Claude が案内します。何を打っても始まりますので、迷ったら下の文をそのままお使いください。

はじめまして。よろしくお願いします。

こう見えたら成功です

Claude が名乗って、登阪さんから伺っている内容が合っているかどうかを聞いてきます。違っていたら、遠慮なく違うと言ってください。そこから直します。

ときどき「これをしていいですか」と聞かれます

この作業場は、ファイルの読み書きは確認なしで通るように設定してあります。いちいち押さなくて大丈夫です。

それでも、何かをインストールしたり、外に送ったりするときには確認が出ます。そこだけは安全のために残してあります。出てきたら「はい」で進めて構いません。

英語や記号がたくさん流れます。読まなくて大丈夫です

Claude が作業している間、画面に文字が流れます。全部読む必要はありません。大事なことは日本語で伝えます。

作ったものは、画面の中でそのまま開けます。ファイルを探しに行かなくて構いません。

もし名乗らなかったら

Claude が引き継ぎ内容の話をせず、普通に返事をしただけなら、選んだフォルダが違っています。ひとつ前の手順に戻って、作業場のフォルダを選び直してください。

このあとは、まず3つだけ伺います。そのあと、スプレッドシートを1つ見せていただいて、実物を見ながら進めます。分からないものは「分からない」で大丈夫です。

知っておいていただきたいこと

  • 今日、名簿は1件も要りません。まず道具を入れて、話をするところまでです
  • 作ったものは、元に戻せます。この作業場は変更の履歴を持っています。「さっきの状態に戻して」と言えば戻ります。星野さんが操作を覚える必要はありません
  • ただし、スプレッドシートの原本は履歴に入りません。GitHub に上げない設定にしてあるためです。原本は、別の場所にもコピーを取っておいてください。ここだけは元に戻せません
  • 原本には書き込みません。読むだけです。加工したものは別のファイルに作ります
  • Claude が読んだ内容は、Claude のサービス（Anthropic 社）に送られて処理されます。いま星野さんがお使いの AI と同じ仕組みです。お客さんの情報をどこまで読ませるかは、進めながらご相談します
  • ファイルそのものは、星野さんのパソコンに置いたまま扱います。GitHub には上がりません
  • 途中でやめて大丈夫です。上の「今日やること」に印を付けておけば、次に開いたとき続きが分かります

次に開いたとき

作業場のフォルダの中の はじめに.html を、いつでもダブルクリックで開けます。このページは消さないでください。

2日目以降にやることは、Claude が案内します。何を打っても始まります——「続きから」とだけ打っていただければ、前回の続きを見つけて再開します。

いま何が決まっているかを見たいとき

同じフォルダの中の わかったこと.md に、伺った内容が溜まっていきます。計画.html はダブルクリックで開けます。どちらも、まだ何も決まっていないうちは空欄だらけです。それが正常です。

うまくいかないときは、画面に出ている文をそのまま、いつもの連絡先で登阪さんに送ってください。それだけで、たいてい原因が分かります。うまく説明しようとしなくて結構です。
この作業場は登阪さんが用意したものです。中身について気になることがあれば、フォルダの中の 引き継ぎ.md に、何が引き継がれているかが書いてあります。
