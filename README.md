# 星野さんの作業場

教室ごとに分かれているスプレッドシートを、ひとつにまとめて見られるようにするための作業場です。
登阪さんが用意しました。

---

## この画面をご覧の方へ（最初にすること）

いま見えているのは GitHub の画面です。ここでは中身が読みにくいので、
**まずこのフォルダを、ご自身のパソコンに持ってきてください。**

1. **GitHub Desktop を入れます** — https://desktop.github.com/download/
   - Mac は「Apple silicon」と「Intel chip」の2種類があります。近年の Mac はほとんど Apple silicon です
   - Windows は「Download for Windows (64bit)」を選びます
2. **GitHub Desktop を起動して、いまお使いの GitHub アカウントでサインイン**します
3. **Clone a repository**（リポジトリをクローン）を選び、この作業場を選んで、
   保存する場所を決めて **Clone** を押します

保存した場所にフォルダができたら、その中の **`はじめに.html`** をダブルクリックで開いてください。
**そこから先の手順は、そのページに全部書いてあります。**

---

## 中に入っているもの

> **この画面でファイル名を押さないでください。**
> GitHub は中身をそのまま文字で表示するので、記号だらけの画面が出てきます。壊れているわけではありません。
> 手元に持ってきてから開けば、普通に読めます。

- **はじめに.html** — 作業場の開きかた（手元に持ってきてから開いてください）
- **計画.html** — 何をどの順番で作るか。やりとりが進むと埋まっていきます
- **引き継ぎ.md** — 登阪さんから引き継がれている内容
- **わかったこと.md** — やりとりの中で分かったことが溜まっていきます
- **スプレッドシート** — お使いのスプレッドシートを入れる場所（中身は GitHub に上がりません）
- **CLAUDE.md** — Claude への指示（星野さんが読む必要はありません）

## お客さんの情報について

名簿や売上のファイル（`.xlsx` `.csv` など）と、`スプレッドシート` フォルダの中身は、
**星野さんのパソコンに置いたまま**扱います。GitHub には上がりません（`.gitignore` で止めてあります）。

ただし、**やりとりの記録（`わかったこと.md` `計画.html`）は GitHub に上がります。**
ここにお客さんの氏名や電話番号を書き写さないよう、Claude に指示してあります。
もし書かれているのを見つけたら、Claude に「消して」と言ってください。

なお、**Claude が読んだ内容は Claude のサービス（Anthropic 社）に送られて処理されます。**
いまお使いの AI と同じ仕組みです。どこまで読ませるかは、進めながらご相談します。

## 困ったとき

画面に出ている文をそのまま登阪さんに送ってください。それだけで、たいてい原因が分かります。
