## この画面をご覧の方へ（最初にすること）

いま見えているのは GitHub の画面です。ここでは中身が読みにくいので、
**まずこのフォルダを、ご自身のパソコンに持ってきてください。**

1. **GitHub Desktop を入れます** — https://desktop.github.com/download/
   - Mac は「Apple silicon」と「Intel chip」の2種類があります。近年の Mac はほとんど Apple silicon です
   - Windows は「Download for Windows (64bit)」を選びます
2. **GitHub Desktop を起動して、いまお使いの GitHub アカウントでサインイン**します
3. **Clone a repository**（リポジトリをクローン）を選び、この作業場を選んで、
   保存する場所を決めて **Clone** を押します

保存した場所にフォルダができたら、その中の **`はじめに.html`** をダブルクリックで開いてください。
**そこから先の手順は、そのページに全部書いてあります。**
